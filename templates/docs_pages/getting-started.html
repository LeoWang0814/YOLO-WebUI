Requirements

Use Python 3.10 or later with the dependencies in requirements.txt. The Workbench is self-hosted: it has no sign-in, no cloud project store, and no multi-user coordination layer.

Scope

Use this application for local, axis-aligned YOLO Detect training and prediction. It does not add segmentation, pose, classification, OBB, or hosted collaboration workflows.

Launch the Workbench

From the project directory, start the application with:

python app.py

The default address is http://127.0.0.1:7860. Set YOLOV10_WEBUI_HOST and YOLOV10_WEBUI_PORT before launch to override the bind address. A direct Uvicorn launch is also supported for a custom local port.

Your first training run

  1. Open Train and enter one local dataset folder.
  2. Select Inspect. Continue only when the dataset result is Ready for YOLOv10 Detect.
  3. Select a pretrained model or local .pt checkpoint, then choose epochs, image size, batch, workers, and device.
  4. Review the live command preview, optionally enter a run name, and select Start training.
  5. Follow download, epoch, and log progress. Open the completed run from Runs.

First prediction

  1. Open Predict and select a model.
  2. Provide uploaded images, one video, or a local source path.
  3. Set confidence, IoU, image size, and device as needed.
  4. Select Run prediction, then inspect generated media in the Results panel or Runs archive.
One active run

The Workbench manages one Ultralytics training or prediction process at a time. Wait for it to finish or stop it before starting another run.
