Glossary

Artifact
A file produced or persisted by a run, such as an output image, weight file, metric CSV, or log.
Cache
A local reusable prepared dataset or verified pretrained model file.
Detect
Axis-aligned object detection with a class and rectangular bounding box per object.
OBB
Oriented bounding box represented by corners or rotation; recognized but not losslessly trainable here.
Prepared dataset
The generated YOLO Detect layout used by Train after strict validation.
Run
One managed local Ultralytics process and its dedicated output directory.
Source
Input media for prediction or the original folder for dataset preparation.
Split
A train, validation, or test partition of a dataset.

Supported capabilities

  • Local pretrained and local .pt models.
  • Local Detect dataset preparation and strict compatible conversion.
  • Train and Predict workflows with grouped Ultralytics advanced parameters.
  • Uploaded images, uploaded video, and local filesystem prediction paths.
  • Local run logs, metrics, generated media, and browser media viewing.

Not supported

  • Prediction URL input or automatic remote-media fetching.
  • Lossy conversion from OBB, segmentation-only, pose, or image-level classification data to Detect labels.
  • Training non-Detect tasks through this Workbench.
  • Concurrent managed training and prediction processes.
  • Built-in accounts, cloud synchronization, or collaboration controls.
