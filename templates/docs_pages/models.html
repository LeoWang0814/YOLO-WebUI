Local models and uploads

Local paths must resolve to an existing .pt file. Uploading a model copies it into the project models/ directory. If the filename already exists, the Workbench appends a numeric suffix instead of overwriting it.

Downloads and verification

Pretrained downloads use the catalog source, retry transient network failures, resume compatible partial downloads, and verify SHA-256 before the model becomes cached. The run progress card shows download percentage or transfer speed, followed by checksum verification.

Model errors

  • Choose a catalog entry for pretrained mode; an arbitrary model name is rejected.
  • For local mode, verify that the path exists and ends in .pt.
  • If a download fails, keep the connection available and retry the run; invalid partial data is not treated as cached.
