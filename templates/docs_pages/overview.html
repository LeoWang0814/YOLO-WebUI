What it is

The Workbench is a local interface around the bundled Ultralytics CLI. It prepares compatible detection data, resolves a model, creates a timestamped run directory, and displays live process output and artifacts.

Train
Prepares a local detection dataset and runs yolo detect train.
Predict
Runs yolo detect predict against local media or a path.
Runs
Reads persisted artifacts under the local run archive.

Workflow lifecycle

  1. Configure a form and inspect its generated command.
  2. Start one managed run; the Workbench creates an isolated local run directory.
  3. Resolve or download the selected model, then launch the CLI process.
  4. Persist command metadata and log output while the process runs.
  5. Review metrics, weights, images, video, and logs after completion.

Product limits

  • Only axis-aligned object detection is trainable through this interface.
  • Prediction supports local uploads and paths, not URL sources.
  • Dataset preparation is local-only and will block ambiguous or lossy conversions.
  • Stopping a run requests process termination; partial artifacts may remain in that run directory.
