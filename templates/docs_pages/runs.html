Run list

Runs lists local directories under runs/train and runs/predict that contain content. Search filters by name; type controls show All, Train, or Predict records. The Updated column comes from the local directory modification time.

Run details

Open a row to read the saved command, captured log, and artifacts. Training details show metrics when results.csv exists. Prediction details show image and video artifacts. New training or prediction links return to the corresponding empty workflow form.

Run states

Queued / resolving model
The manager accepted the request and is resolving local or pretrained weights.
Preparing source / running
The local process is about to start or is emitting output.
Completed
The process exited successfully.
Failed / stopped
The process returned an error or was terminated after a Stop request.
Disconnected
Live in-memory status was lost after service restart; persisted run artifacts and logs may still be available.

Artifacts

Every managed run records args.json, command.txt, meta.json, and run.log. Training can add weights and result metrics; prediction can add generated images or video. Artifact counts in Runs only include visible output media, not staged source uploads.
