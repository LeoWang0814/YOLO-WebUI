Storage locations

LocationPurpose
runs/train/Managed training runs, logs, metadata, weights, metrics, and generated training artifacts.
runs/predict/Managed prediction runs, staged uploads, logs, metadata, images, and video outputs.
weights/<release>/Verified pretrained model cache.
models/Local checkpoints uploaded through the Workbench.
datasets/_prepared/<fingerprint>/Prepared Detect dataset cache, generated YAML, labels, source manifest, and conversion report.

Data lifecycle

Dataset preparation reads a source folder without modifying it. The prepared cache hard-links source images where the filesystem permits or makes byte-for-byte copies otherwise. Prediction uploads are staged inside the prediction run directory so the original local upload name does not become an output artifact. Generated run metadata records arguments, command text, runtime details, and logs.

Privacy and access

Dataset inspection, run execution, media processing, and artifact viewing happen on the machine hosting the Workbench. The app does not upload dataset images or fetch remote prediction URLs. Pretrained model downloads are the only normal network operation and use the configured catalog source. The application has no built-in authentication layer, so bind it only to an address appropriate for your environment.

Retention

Runs, model caches, uploads, and prepared datasets persist until removed from local storage. Deleting a source dataset does not remove its prepared cache automatically; deleting a prepared cache does not modify its source. Stop or close the Workbench before manually cleaning active run directories.
