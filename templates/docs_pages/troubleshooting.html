Dataset errors

Blocked or ambiguous
Keep one known annotation format in the folder and include its required class/configuration files.
Missing or duplicate image
Make annotation image references resolve to exactly one local image.
Invalid box
Correct degenerate, non-numeric, or out-of-bounds source coordinates; the Workbench does not clamp boxes.
Empty train/validation split
Provide declared train and validation content or enough images for a generated split.
Unexpected cached result
Select Inspect after source changes. Cache reuse is based on source location, file names, sizes, and modification timestamps.

Model errors

  • Confirm that a local checkpoint path exists and ends in .pt.
  • For uploads, choose only a .pt file; the UI reports validation errors in place.
  • For failed downloads, check network access and disk space, then retry. A checksum mismatch prevents the file from entering the cache.

Run errors

  • A conflict means another training or prediction job is active. Wait, open it in Runs, or stop it.
  • An invalid GPU choice means no compatible CUDA device is available or no GPU was selected.
  • A run name must be a single directory name; it cannot contain path traversal or overwrite an existing requested run.
  • After a service restart, live job status can become disconnected even though saved files remain in Runs.

Output errors

Open the run log first when expected artifacts are absent. A process can fail before it writes images, video, metrics, or weights. If video cannot be converted to browser-ready MP4, the Workbench keeps the original when the browser can play it; otherwise open the local artifact with a suitable media player.
